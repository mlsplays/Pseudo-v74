# Pseudo-v74
## A conversion kit to revert the SystemUX a rootable Quest 2, Pro, 3, or 3s 


# Instructions (manual)

 1. Root your headset with Singularity (if not done already)
 2. In AIO tweaks under UI switch to the Dock UI
 3. Download and extract the zip from releases
 4. Install [CorePatch](https://github.com/LSPosed/CorePatch/releases) and Vector (in Singularity under apps and modules)
 5. In Vector click on CorePatch and check system_server then Soft reboot
 6. Open CorePatch (app) and enable Bypass downgrade and Bypass verification 
 7. Run oculuspreferences --setc ocui_premium_ui_enabled 0 from Singularity terminal
 8.  Then install the apps in the folder, your done!
 
 (Note: You will have to install the apps again every reboot)
